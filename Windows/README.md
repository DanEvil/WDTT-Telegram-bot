# K.O. Gateway — Windows-приложение

Одна кнопка «Подключиться» для входа в экосистему K.O. Gateway, плюс карточка активной подписки и кнопка оплаты:
- **WDTT** — VPN-панель K.O. Gateway (ссылки `wdtt://`, DTLS/WG/RAW)
- **AIVPN** — замаскированный UDP-туннель (infosave2007/aivpn, ссылки `aivpn://`)

## Быстрый старт

```bat
# нужно Python 3 (уже есть на этом ПК: C:/Users/nenas/Voice/bin/python3)
python Windows/main.py
```

## Сборка в .exe (однофайловый, без консоли)

```bat
pip install pyinstaller
pyinstaller --noconsole --onefile --name "K.O. Gateway" Windows/main.py
# готовый .exe: dist/"K.O. Gateway.exe"
```

## Как пользоваться

1. Запустите `main.py` (или `.exe`).
2. Войдите: через Telegram (код привязки от бота @KO_Gateway_bot) или через email (код из письма).
3. Ссылки подключения (WDTT, AIVPN, OpenFlux) загружаются **автоматически по вашему аккаунту** — вводить их вручную не нужно.
4. Внизу экрана переключайтесь между вкладками **Главная** и **Настройки**.
5. На **Главной** нажмите **🔌 Подключиться** или **💳 Оплатить**:
   - «Подключиться» — выбрать профиль (WDTT VPN / AIVPN / OpenFlux), приложение само подтянет сервер и порты из вашего аккаунта, затем соединится.
   - «Оплатить» — выбрать тариф из списка, нажать «Оплатить через ЮKassa», откроется страница оплаты в браузере.
6. Выберите профиль: **WDTT VPN**, **AIVPN** или **OpenFlux**.
   - Для WDTT берутся из панели (вкладка «Моя подписка» в боте/сайте) — `wdtt://IP:56000:56001:56003:...`
   - Для AIVPN — `aivpn://...` из конфига клиента AIVPN.
6. Нажмите **Подключиться**. Статус станет зелёным — трафик идёт через выбранный профиль.
7. Повторное нажатие — отключение.

**Настройки** хранят выбранный профиль, адрес сервера, порты/ссылку, токен и URL API сайта, а также два набора правил раздельного туннелирования:

- **Прямое подключение (мимо VPN)** — сайты и IP, которые обходят туннель (российские домены, Apple Music и т.п.). Настраиваются во вкладке «Прямое подключение».
- **Через туннель VPN** — сайты и IP, которые принудительно пускаются через VPN-шлюз, даже если они попадают в список прямых. Настраиваются во вкладке «Через туннель VPN».

Для каждой группы можно добавлять домены, IP/сети (CIDR) и имена процессов. Есть автообновление списков по текстовому URL. Кнопка «Применить к системе» генерирует `direct_routes.bat` с командами `route ADD` и записями в `hosts` (требуются права администратора).

## Авторизация (войти обязательно)

При первом запуске открывается окно входа. Можно войти двумя способами:

### Вход через Telegram
1. Нажмите «Открыть бота @KO_Gateway_bot»
2. В боте отправьте команду `/bind` — вы получите код привязки
3. Вставьте код в поле «Код привязки» и нажмите «Подтвердить код»

### Вход через email
1. Введите email и пароль
2. Нажмите «Отправить код на email» — код придёт на вашу почту
3. Введите полученный код в поле «Код подтверждения» и нажмите «Подтвердить код»
4. Код действителен 15 минут

### Пропуск входа
Можно нажать «Пропустить (без входа)» — приложение откроется без авторизации, но некоторые функции (покупка подписки, просмотр профиля) могут быть недоступны.

## Карточка подписки

На главном экране отображается блок «Активная подписка» с тарифом, статусом, сроком действия, остатком дней, трафиком и количеством устройств:

- **Тариф** — название текущего тарифного плана
- **Статус** — Активна / Неактивна
- **Действует до** — дата окончания подписки
- **Осталось дней** — сколько дней осталось до истечения
- **Трафик** — использовано из лимита (ГБ) или «безлимит»
- **Устройства онлайн** — сколько устройств сейчас подключено к VPN
- **Лимит устройств по тарифу** — сколько устройств позволяет тарифный план

Данные загружаются с локального сайта (`/api/v1/me`) — нажмите **🔄 Обновить данные**, чтобы синхронизировать. Сохраняются в `subscription.json`.

## Раздельное туннелирование (исключения из VPN)

Некоторым ресурсам (российским доменам, Apple Music и т.п.) нужно подключаться напрямую, минуя туннель.
Для этого нажмите кнопку **«🚫 Исключения из туннеля…»**:

- **Вкладка «Домены»** — введите домен (например, `yandex.ru`) и нажмите `+`, чтобы добавить в список прямого подключения. Также есть автообновление списков по текстовому URL.
- **Вкладка «IP / сети»** — списки IP/сетей в формате CIDR (например, `95.163.0.0/16`).
- **Вкладка «Приложения»** — нажмите «Обновить список», чтобы отсканировать установленные в Windows программы. Поставьте галочку нап той программы, которую нужно пускать напрямую (мимо VPN). Список фильтруется по поиску.
- **Применить к системе** — генерирует `direct_routes.bat` с командами `route ADD` и записями в `hosts` (требуются права администратора).

То же самое доступно во вкладке **«Через туннель VPN»** — для ресурсов, которые нужно принудительно пускать через туннель.

Все настройки хранятся в `config.json` (секции `direct_routes`, `tunnel_routes`, `connection_failover` и `speed_test`).

## Авто-переключение при медленном соединении (AIVPN → WDTT → OpenFlux)

При нажатии «Подключиться» приложение автоматически анализирует задержку к серверу для каждого доступного способа (AIVPN, WDTT, OpenFlux) и выбирает **наиболее быстрый с наименьшим пингом**:

1. **Измеряет задержку** к серверу для каждого протокола (AIVPN: порты 443/8443, WDTT: порты 56000/56001/56003, OpenFlux: HTTP-запрос к URL документа транспорта).
2. **Измеряет HTTP-задержку** к контрольным сайтам (Google, YouTube, Apple) через каждый протокол.
3. **Сравнивает результаты** — выбирает способ с наименьшей суммарной задержкой.
4. **Подключается** через выбранный способ и показывает в логе, какой протокол выиграл.

Настройки в разделе «Авто-переключение при медленном соединении» (вкладка «Настройки»):
- **Включить авто-переключение (AIVPN → WDTT → OpenFlux)** — если выключено, используется только выбранный вручную профиль.
- **Порог медленности (мс)** — сайты, отвечающие дольше этого времени, считаются медленными (по умолчанию 3000 мс).
- **Порядок**: AIVPN → WDTT → OpenFlux.

Логи сохраняет выбор в логе приложения, например:
```
Измеряю AIVPN…
AIVPN: ping=45 мс, HTTP=120 мс
Измеряю WDTT…
WDTT: ping=120 мс, HTTP=200 мс
Измеряю OPENFLUX…
OPENFLUX: ping=80 мс, HTTP=150 мс
Выбран AIVPN (ping=45 мс, http=120 мс) — наиболее быстрый
Готово. Трафик идёт через AIVPN.
```

## OpenFlux — дополнительный протокол подключения

OpenFlux (p1neappleXpress/OpenFlux) — TCP/UDP туннель с pluggable transports. Добавлен как третий профиль подключения рядом с WDTT и AIVPN.

**Настройки (вкладка «Настройки», секция OpenFlux):**
- **Транспорт** — yandex, vyandex, mailru, cupsonline, avito или direct
- **URL документа** — ссылка на документ-носитель для транспорта
- **Секрет шифрования** — AES-256-GCM ключ для сессий и `--transports` (опционально)
- **Inbound** — `socks5` (SOCKS5 прокси на `:1080`, без прав администратора) или `tun` (полный туннель, требует Wintun и администратора)
- **Кодек** — `batched` (zstd, по умолчанию) или `legacy` (LZ4)

При подключении через профиль OpenFlux приложение запускает `openflux.exe` с указанными параметрами. Трафик перенаправляется через локальный SOCKS5 прокси (`127.0.0.1:1080`) или виртуальный сетевой интерфейс (режим tun).
