WDTT upstream (ildarmaga/wdtt) — как устроен исходный сервер

Один бинарник wdtt-app = DTLS :56000 (WRAP) + userspace WireGuard + панель :2860 + подписка :2096 · опционально wdtt-xray поверх интерфейса wdtt0

Ядро: DTLS + userspace WG

  • • клиент → DTLS :56000, обфускация WRAP, auth по паролю/vk_hash
  • • vk_hash → VK-видеозвонок → TURN relay (медиарелеи VK), WG гоняется поверх DTLS
  • • userspace WG на wdtt0 (10.66.66.1, юзеры 10.66.66.x) + NAT MASQUERADE
  • • порты: DTLS 56000, WG 56001, RAW direct 56003 (=DTLS+3)

Панель и подписка

  • • web UI :2860 (логин admin/wdtt), REST API — docs/API.md
  • • подписка :2096 отдаёт wdtt:// ссылки клиентам
  • • VK Creator: cookies VK (remixsid) → vk_hash, таблица vk_calls
  • • всё хранится в /etc/wdtt/panel.db (SQLite)

Опциональный Xray (wdtt-xray)

  • • отдельный юнит wdtt-xray.service (BindsTo=wdtt.service), конфиг /etc/wdtt-xray/config.json
  • • redirect-in (dokodemo) ловит трафик интерфейса wdtt0 → outbound (direct/WARP/NL)
  • • панель управляет инбаундами hot-reload'ем (xray api adi/rmi), теги redirect-in/dns-in защищены
  • • в исходнике VLESS — только как outbound/режим Xray, не встроенный протокол сервера
